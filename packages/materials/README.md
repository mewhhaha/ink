# @ink/materials

`@ink/materials` publishes canonical PBR records, linear and encoded color
values, branded material identities, validated material definitions, and typed
texture bindings. The same records feed raster rendering and ray-scene packing.

Material import, mutable libraries, and reference-material conveniences remain
under `@ink/materials/experimental/*`. A material feature becomes stable only
when an editor game proves its effect on rendered pixels.
