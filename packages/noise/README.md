# @ink/noise

The stable surface is the deterministic CPU value-noise path exercised by the
strategy editor game:

- `domain.ts` owns branded seeds and periodic domains.
- `hash.ts` owns deterministic coordinate hashing.
- `value.ts` samples value noise in one, two, or three dimensions.

Batch baking, cellular, fractal, gradient, and WGSL implementations remain under
`@ink/noise/experimental/*`. They do not become stable through the strategy
scenario.
