# Kenney Modular Dungeon Kit

`gate-door.obj` and `stairs.obj` come from Kenney's Modular Dungeon Kit 2.1:

- https://kenney.nl/assets/modular-dungeon-kit
- downloaded 2026-08-24
- Creative Commons CC0; the original `License.txt` is included beside the models

Only the two OBJ meshes used by the example are retained from the pack.
Their optional per-vertex RGB values were removed because Ink's OBJ boundary
accepts standard three-coordinate positions and computes material color itself.
