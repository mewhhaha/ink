func events 
func events: Clip -> F32 -> F32 -> Bool -> #[U32]

Crossings in (previous,current], including every loop and exact boundaries. Events must be sorted in [0,duration); returned ids preserve temporal order. Reverse playback yields no events; the caller can request a forward window.

Inverse bind transforms for joints from a skeleton's local rest pose. Rejects invalid parent order, out-of-range joint indices or singular bones.
