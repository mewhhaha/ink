ink/gameplay/attributes

4 types · 7 values

Gameplay Attribute & Modifier Stack (GAS-style): deterministic evaluation of base values + stacked Add, Multiply and Override modifiers with min/max clamping, plus timed effect and cooldown ticking.

Key items: Op, Modifier, Spec, Cooldown, evaluate.

blot · runnable example
import * as attrs from "ink/gameplay/attributes"
let spec = $attrs.Spec { base: 10.0, min_val: 0.0, max_val: 100.0 }
let mods = #[$attrs.Modifier { attribute: 0, source: 1, op: $attrs.Add, value: 5.0, remaining: 1.0 }]
attrs.evaluate 0 spec mods // => 15.0

func evaluate 
func evaluate: U32 -> Spec -> #[Modifier] -> F32

Compute the current value of attribute given spec and active modifiers: (base + sum(Add)) * product(Multiply) (or last Override if present), clamped to [spec.min_val, spec.max_val].

func evaluate_all 
func evaluate_all: #[Spec] -> #[Modifier] -> #[F32]

Evaluate every attribute in specs in a single O(A + M) pass.

func tick_modifiers 
func tick_modifiers: F32 -> own #[Modifier] -> #[Modifier]

Advance timed modifiers by dt seconds, compacting expired ones (remaining <= 0). Permanent modifiers (remaining < 0) are untouched.

func remove_source: U32 -> own #[Modifier] -> #[Modifier]
