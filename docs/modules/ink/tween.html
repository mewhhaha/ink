ink/tween

3 types · 10 values

Tweens animate any value whose type has lerp: a -> a -> F32 -> a: F32, Vec2, Vec3, math.Color and math.Quat (slerp) already do, and a game can give its own types one. A value with discrete states, such as a flag, a count or a variant, tweens inside Discrete, which holds its start until the eased progress reaches 1: at the end, or earlier where Back overshoots. Times are the caller's seconds; nothing here keeps a clock.

Key items: Ease, Tween, Discrete, eased, under.

blot · runnable example
import * as tw from "ink/tween"
let $Some anim = tw.make 0.0 100.0 0.0 2.0 $tw.Linear else:
  return 0.0
tw.at anim 0.5 // => 25.0

data Ease 
type Ease is data

Easings are data, so tweens and timelines can be saved and compared. Back overshoots past 1 before settling. Hold stays at 0 until the end; Steps n rises in n equal jumps, reaching 1 at the end.

Functions & Values

func eased 
func eased: Ease -> F32 -> F32

Eased progress for linear progress t, clamped to [0, 1] first. Every ease is exactly 0 at the start (and for NaN) and exactly 1 at the end. Before the end, results that F32 rounding would carry up to 1 stay just below it, so a Discrete value cannot switch early; only Back legitimately passes 1.

func under 
func under: F32 -> F32

Caps a value at the largest F32 below 1.

func steps 
func steps: U32 -> F32 -> F32

For progress in (0, 1): n equal jumps, none for zero steps.

func make 
func make: a -> a -> F32 -> F32 -> Ease -> Maybe Tween a

func reversed 
func reversed: Tween a -> Tween a

Swaps the ends over the same span, keeping the ease. A symmetric ease (Linear, Smooth, Smoother, CubicInOut) retraces the motion backwards; an asymmetric one keeps its character, so a reversed CubicIn still starts slowly.

func toward 
func toward: Tween a -> F32 -> b -> F32 -> Ease -> Maybe Tween b ! { | e}

Interrupts tween at time: a new tween from wherever it is now to to, so redirecting never jumps.
