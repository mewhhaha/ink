ink/menu

4 types · 22 values

A column of controls on the screen that keys and the pointer work, as a game's menus are: where the rows lie, which row has the focus and which slider the pointer drags, what an event does to them, and the sprites that show them. The game decides what the rows are and what pressing and changing them does (ui.Outcome).

Key items: Focus, Layout, Words, Style, column_into.

func receive 
func receive: Focus -> Layout -> #[Control] -> Event -> (Focus, Outcome)

What event does to controls laid out as shape: the focus after it and the outcome. Keys work as ui.key has them. The pointer focuses the row it is over; a click presses a button, steps a toggle, steps a choice back on the left half of its value and on on the right, and sets a slider where it falls on its bar, which then follows the pointer until the button is let go.
