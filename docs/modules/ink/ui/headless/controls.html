ink/ui/headless/controls

7 types · 26 values

Headless accessible atomic and grouped controls with zero rendering coupling:

  • Tri-state Checkbox (unchecked / checked / mixed + select-all aggregator)
  • Switch and ToggleButton
  • RadioGroup (roving arrow/Home/End navigation, skips disabled items, RTL-aware)
  • Spinbutton (step, large PageUp/PageDown step, Home/End clamping)
  • Progressbar (determinate and indeterminate)

Key items: Checkbox, Switch, ToggleButton, RadioItem, make_checkbox.
