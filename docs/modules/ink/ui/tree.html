ink/ui/tree

11 types · 58 values

The interface as assistive technology and the keyboard see it: the nodes the game declares as it draws each frame (ui builds and declares them), and the keyboard focus that moves through them. Callers present nodes to their accessibility host through an adapter.

The game drives the focus, in every host alike: while a node has it, Tab and Shift+Tab move it through the focusable nodes (of a tab list's tabs, only to the chosen one), Up and Down between the rows of a list, menu, dialog or page, Left and Right between the tabs or tools of a bar or step a slider, and Enter and Space activate the focused node (or step it up). Those keys reach the game as UiAction events on the node, the same events assistive technology sends through the host, so a system that handles a node's actions handles both. F10 moves the focus into the interface and back out; Escape and a click leave it. While a modal dialog is open the focus stays in it. A focused text box receives editing keys unchanged.

Key items: Span, Node, StoredNode, Tree, from_nodes.

blot · runnable example
let id = key 2 5
id // => 131077

data Span 
type Span is data

A node as the game declares it: id from a stable key (key), parent its parent's id or 0 at the top, role (vocabulary.role_), its text in code points, where it lies on the screen (an empty rectangle for one not drawn), its states (checked, expanded and selected in vocabulary.state_, live in vocabulary.live_), a range's value and bounds, and the actions it takes (bit of each vocabulary.action_). focused is the focus's to set (settle). Flat range into a caller-owned codepoint label pool.

alias Stop 
type Stop = { id: U32, parent: U32, role: U32, actions: U32 }

What the keys move through of a node the last frame declared: its id, its parent's, its role and the actions it takes. A flat structural record, so an array of them packs into consecutive words instead of boxing each.

alias Return 
type Return = { scope: U32, node: U32 }

The keyboard focus: the focused node's id, or 0 while the game's world has the keys; whether Shift is held; the open modal dialog's id (0 for none); and the last frame's nodes, those Tab stops at in order, and all the nodes the focus can reach. It is saved with the state (not with scenes), the last frame's nodes included: a restored moment's keys move through what its last frame declared, as they did the first time.
