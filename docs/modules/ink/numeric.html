ink/numeric

7 types · 2 traits · 1 effects · 99 values

Zero-abstraction consumer-controlled NaN / non-finite handling for Blot & Ink.

Combines four zero-overhead layers so callers choose exact cost and recovery:

  1. Unboxed opaque validated scalars (Finite, NonZeroFinite, UnitF32) which lower directly to raw Wasm f32 registers (Kind.floating32).
  2. Zero-sized compile-time NanPolicy traits (FastIeee, Fallback, StrictTrap, or caller-defined policies) — static monomorphization, zero vtables, usable inside pure spark SIMD loops and #kernel.
  3. Scoped Numeric algebraic effect (with Numeric = { non_finite: ... }:) whose happy path never touches the effect runtime; consumers choose dev traps, playtest telemetry logging, or release recovery per scope.
  4. Compile-time #for field in #fields t: record validators/sanitizers that name the exact offending field.name with zero runtime reflection.

Key items: NanPolicy, FiniteField, Numeric, Finite, min_finite.

blot · runnable example
import * as numeric from "ink/numeric"
let dt = numeric.Finite.from_or numeric.Finite.zero 2.0
let mass = numeric.NonZeroFinite.from_or numeric.NonZeroFinite.one 4.0
let safe = numeric.div_with numeric.fallback 0.0 1.0 0.0
let recovered = numeric.run_fallback (func () => numeric.div (-1.0) 1.0 0.0)
#[numeric.Finite.div_by dt mass, safe, recovered] // => #[0.5, 0.0, -1.0]
