ink/ai/avoidance

4 types · 16 values

Local collision avoidance: ORCA (optimal reciprocal collision avoidance) in the form of RVO2 (van den Berg, Guy, Lin, Manocha). For one agent, every neighbouring agent and every nearby static obstacle edge yields a half-plane of permitted velocities; an incremental 2D linear program picks the permitted velocity closest to the preferred one, and a 3D linear program (minimum worst violation of the agent constraints) runs when the constraints are infeasible. The solver reproduces RVO2's constraint construction and its linearProgram1/2/3 step for step, in F32.

Everything is explicit: the caller owns agent rows, the neighbour lists from its own spatial partition, obstacle storage, time horizons and the time step. Agents are flat rows of five numbers (x, y, vx, vy, radius) in one pool; the plane is (x, y), so a 3D game maps its ground plane (x, z) onto it.

Determinism: candidates are sorted by squared distance, then by id (agent index or obstacle vertex id), and at most max_neighbours nearest agents are used, so the result does not depend on the order the caller listed them. Neighbours equal to the agent itself, out of range, or nonfinite are ignored. Zero time horizon: only already-colliding neighbours constrain the agent (resolved over one time step); anticipation needs a positive horizon. Coincident agents separate along +x for the lower index and -x for the higher. Invalid inputs (nonfinite numbers, negative radius or speed, nonpositive time step, agent index out of range) return a zero velocity with status invalid.

Lines are written to work.lines as four numbers each (point x, point y, direction x, direction y); a velocity v satisfies line k when det(direction, point - v) <= 0. After a call, work.lines holds the lines the result was computed against (obstacle lines first), for inspection.

Key items: Params, Work, Obstacles, Velocity, work.

func add_into: own Obstacles -> View F32 -> View U32 -> (Bool, Obstacles)

Appends closed polygons (or two-vertex segments) to the set. points are x, y pairs, counts the vertices per obstacle. Counter-clockwise polygons keep agents outside, clockwise ones keep them inside (a boundary); two vertices make a wall that blocks from both sides when both vertex ids are supplied. Returns false and leaves the set unchanged for fewer than two vertices per obstacle, a count mismatch, nonfinite points or a zero-length edge.
