ink/handles

4 types · 17 values

Payload, dense-owner index, slot metadata and free stack live inside one caller-owned Store so updates thread ownership directly without hidden stores.

Key items: Handle, Slot, Metadata, Store, handle_pool.

blot · runnable example
type Tag is data = $Tag
let store: Store [Tag, U32] = empty $Tag 1 1 8
let (found, store) = insert $Tag 42 store
let $Some h = found else:
  return 0
Maybe.unwrap_or 0 (get h store) // => 42

data Store 
type Store kind value is data

Element payloads are fixed-layout rows; variable data uses caller-owned pools plus spans/borrowed views/links, never owning array fields.
