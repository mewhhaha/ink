func advance 
func advance: Program (a, b) -> State c -> own Array { owner: U32, remaining: U32 } -> own #[U32] -> F32 -> U32 -> U32 -> (a -> (Tick -> (c -> Result c))) -> (b -> (c -> Bool)) -> (U32 -> (c -> c)) -> (Maybe Advanced c, Array { owner: U32, remaining: U32 })

Time is consumed once as it crosses immediate steps. Budget exhaustion returns remaining seconds; callers choose whether to carry or drop them. A pending action consumes the tick; a completed action explicitly returns its unused time. All callbacks are pure and local state is ordinary saved data.
