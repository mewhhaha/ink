ink/spatial

5 types · 27 values

Caller-owned flat bounding-volume tree. Refit hands the updated index back. Callers explicitly copy an index before retaining a snapshot.

Key items: Bounds, Index, Read, Cells, read.

blot · runnable example
import * as math from "ink/math"
let bounds: #[F32] = #[]
let order: #[U32] = #[]
let leaves: #[U32] = #[]
let boxes = #[
  $Bounds { low: math.vec3 0.0 0.0 0.0, high: math.vec3 1.0 1.0 1.0 },
  $Bounds { low: math.vec3 5.0 0.0 0.0, high: math.vec3 6.0 1.0 1.0 },
]
let tree = build_into (access 0 bounds order leaves) boxes
(query (read tree) (math.vec3 0.2 0.2 0.2) (math.vec3 0.8 0.8 0.8)).length // => 1

data Cells 
type Cells starts items is data

A uniform grid of square cells over the floor plane (x, z), bucketing points so a neighbour query visits the points near it rather than all of them. Cell c (row-major from left, front) holds items[starts[c] .. starts[c + 1]], point indices ascending. Points with a non-finite x or z are left out. The cells span the points' bounds; where cells of size would number more than four a point (plus 64), they grow until they do not, and a size that is not positive and finite makes one cell of them all.

func with_areas 
func with_areas: F32 -> #[Bounds] -> (Cells (View U32, View U32) -> a ! { | e}) -> a ! { | e}

Items with extent bucketed like cells: item i is listed in every cell its bounds' x and z overlap, so cell c holds the indices of the items that may cover it, ascending. Items with non-finite or inverted bounds are left out. The cells span the listed bounds. Cells of size grow by a quarter until they number at most four an item and list at most eight an item (each plus 64); a size that is not positive and finite starts from half the square root of the bounds' area per item. A point's cell is found with span and no reach.
