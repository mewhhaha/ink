ink/net/rollback

4 types · 31 values

GGPO-style rollback for deterministic peer-to-peer play. A caller's step is a pure function of its state and one frame of input lanes; this module owns only input rings, confirmation bookkeeping and the schedule of rollback. Nothing here owns the game state, the saved-state ring, the clock or the transport: callers pass their own state and snapshot ring owners with own and compile-known callbacks copy between them.

Frame f is the state before f's inputs apply. Inputs are fixed-width U32 lanes. A local sample taken while simulating frame f applies at f + delay; every peer starts with frames [0, delay) confirmed as zeros.

Callbacks (all compile-known, passed by the caller): predict player frame lane last_word -> word (repeat_last by default) step state inputs -> state (inputs: players * lanes) save slot state ring -> ring (copy state into slot) load slot ring state -> state (copy slot over state) checksum slot ring -> word Slots run 0 .. snapshots config; slot of frame f is f % snapshots config.

Key items: Config, Rollback, Header, Outcome, ring_size.

blot · runnable example
let cfg = $Config { players: 2, lanes: 1, window: 6, delay: 2, local: 0, interval: 4, redundancy: 4 }
#[snapshots cfg, local_frame (make cfg)] // => #[7, 2]

func resolve 
func resolve: (U32 -> (U32 -> (U32 -> (U32 -> U32)))) -> (own a -> (#[U32] -> a)) -> (U32 -> (a -> (own b -> b))) -> (U32 -> (b -> (own a -> a))) -> (U32 -> (b -> U32)) -> own Rollback -> own a -> own b -> (Rollback, a, b)

Roll back to the earliest mispredicted frame and resimulate to the present with the inputs now known. Depth never exceeds the window because frames before the frontier cannot mismatch and snapshots cover [current - window, current]. Also records newly final checksums. Call before advance, or alone while draining the network after the last frame.

func advance 
func advance: (U32 -> (U32 -> (U32 -> (U32 -> U32)))) -> (own a -> (#[U32] -> a)) -> (U32 -> (a -> (own b -> b))) -> (U32 -> (b -> (own a -> a))) -> (U32 -> (b -> U32)) -> View U32 -> own Rollback -> own a -> own b -> (Rollback, a, b, Outcome)

One simulation tick. local_input is the caller's sample (lanes words) for frame local_frame s. It is consumed only when a frame advances. The tick stalls instead of overrunning when the rollback window is full or a peer has not acknowledged enough of our inputs for the ring to keep them.

func advantage_word

Frames we run ahead of player, estimated at the last packet from it. The caller supplies the one-way latency in frames from its own clock. Zero until a packet arrives.

func advantage 
func advantage: Rollback -> U32 -> U32 -> F32
func recommend 
func recommend: Rollback -> U32 -> U32

Frames the caller should stall (skip advance, still resolve) to even out the lead over the peer that is furthest behind: half the difference between our advantage and the peer's reported one. Zero when not ahead.

func encode 
func encode: Rollback -> U32 -> U32 -> #[U32]

Packet: magic, version, players, lanes, sender, sender frame, advantage, report frame, report checksum, first input frame, input count, one ack per player (first frame the sender still lacks), count * lanes input words, hash. Inputs repeat from the receiver's acknowledgement, oldest first, at most redundancy per packet, so any loss pattern still delivers progress.

func decode_header 
func decode_header: Config -> View U32 -> Maybe Header

Strict structural validation: framing, configuration, sender, bounds and the trailing hash. Nothing is applied. Header fields are returned for receive.

func receive 
func receive: View U32 -> own Rollback -> (Rollback, Bool)

Apply a valid packet; any malformed packet changes nothing and returns false. Out-of-order, duplicated and overlapping packets are safe.
