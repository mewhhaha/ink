ink/net/replication

4 types · 34 values

Snapshot interpolation and delta replication over numeric lanes. A lane is one exact U32 word (IEEE bits for floats), so deltas compare and preserve bit patterns, NaNs included. Callers own clocks, sequence numbers, lerp policy and transport; nothing here reads time or keeps hidden state.

Snapshots is one fixed-capacity store of timestamped lane rows kept in ascending time order. The server uses it as its baseline history and the client as its jitter buffer. Rows copy their lanes into the store's pool.

Key items: Snapshots, Kind, Sample, Header, snapshots.

func sample 
func sample: Snapshots -> F32 -> F32 -> (U32 -> (U32 -> (U32 -> (F32 -> U32)))) -> own #[U32] -> (#[U32], Sample)

Render-time sampling. time is the caller's server-time estimate minus its render delay. Exact snapshot times copy that row untouched. Between rows lerp lane a b t blends each lane. Past the newest row a prediction runs at most max_extrapolation seconds beyond it (weight above one); later times hold the extrapolated end. Before the oldest row, or with one row, the nearest row is held. out receives lanes only when the store is not empty.
