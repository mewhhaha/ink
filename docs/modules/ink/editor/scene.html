ink/editor/scene

7 types · 43 values

Headless 3D scene-graph editor built purely in Blot over ink/scene_graph, ink/gizmos, ink/transform, ink/math and ink/render. Hosts supply windowing, pointer rays, materials and rendering; all picking, gizmo math, undo/redo history and play-in-editor snapshot/restore live here.

Key items: Snap, GizmoStyle, State, Command, new_state.
