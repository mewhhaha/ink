ink/graphics

3 types · 6 values

What the host needs to draw a frame's sky and shadows, worked out from the frame and the player's shadow quality.

Key items: Sky, Tier, Shadow, sky, ambient_from_sky.

Types

data Sky 
type Sky is data

The sky: overhead a little deeper than the clear color, a horizon paled toward grey by the ambient light and warmed by the sun, haze below it, the way toward the sun (or the moon), and how dark the night is, for stars.

Constructors

$Sky
  • zenith: Vec3
  • horizon: Vec3
  • ground: Vec3
  • sun: Vec3
  • night: F32
data Tier 
type Tier is data

What a shadow quality tier buys. texels is the size of each sun cascade's map (0 for no shadows at all) and cascades how many there are, nearest first. filter is how the host softens a shadow's edge (0 hard, 1 percentage closer, 2 percentage-closer soft shadows with a penumbra that widens with the distance to the caster), contact the steps of its fine march toward the sun for contact shadows (0 for none), and local how many point and spot lights may cast shadows, each into a map of local_texels by local_texels.

Constructors

$Tier
  • texels: U32
  • cascades: U32
  • filter: U32
  • contact: U32
  • local: U32
  • local_texels: U32
data Shadow 
type Shadow is data

The frame's shadows: the sun's cascades fitted to the frame's camera and light (shadow.fit), one light view they all share, and the quality tier of texels with the frame's shadow settings. Empty (texels 0, no cascades, no local casters) when the tier is off or the camera or light cannot be fitted, such as a frame that sets no view or projection. Cascades are nearest first and cover the camera's near plane out to the shadow distance; each window moves in whole texels of its own texel.

Constructors

$Shadow
  • view: Mat4
  • texels: U32
  • filter: U32
  • softness: F32
  • contact: U32
  • contact_length: F32
  • local: U32
  • local_texels: U32
  • cascades: #[Cascade]

func ambient_from_sky 
func ambient_from_sky: Sky -> Vec3 -> Diffuse

The sky's diffuse light for the host to shade with: the nine SH terms of the sky above (no sun, which the directional light brings), scaled so its average over all directions is the lighting's flat ambient, and the tint that scaling is, which glossy reflections of the same sky reuse. White albedo facing a normal shows environment.evaluate of the coefficients.

func tier 
func tier: U32 -> Tier

The shadow policy for the player's quality.shadows choice, which is the size of the sun's maps: 0 off, 1024 low, 2048 medium, 4096 high; a size between falls into the tier above it.

texels cascades filter contact local casters (map size) 0 0 hard 0 0 1024 2 PCF 0 0 2048 3 PCSS 12 2 (512) 4096 4 PCSS 20 4 (1024)
