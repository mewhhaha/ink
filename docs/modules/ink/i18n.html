ink/i18n

6 types · 38 values

First-class host-independent internationalization (i18n):

  • BCP 47 tag normalization, fallback chain and RTL language/script detection
  • Unicode CLDR cardinal and ordinal plural category selection
  • Composable single-pass {key} / {0} / {count} message formatting
  • Locale-aware decimal, grouped number and percentage formatting
  • Flat caller-owned translation catalogs with fallback and dual drawn/spoken text

Category codes match pen_protocol::plural_category and pen_runtime::locale.

Key items: Span, Entry, Catalog, Param, ascii_lower.

blot · runnable example
same_ignore_case "en-US" "EN-us" // => true
