ink/pen/simulation

8 types · 40 values

The host's simulation services, which every host answers with the same bits (pen's pen-simulation crate; protocol.blot's PhysicsOperation, ColliderShape, NavmeshOperation, SpatialOperation and NoiseOperation lay the numbers out): rigid-body physics, paths over a navmesh, ray and shape queries against colliders, and noise and heightfields.

A request carries the whole problem: the game keeps its bodies, colliders and areas in its own state and sends them each time, so after a rewind or reload it asks the same and is answered the same. Each request below is made through ink/services' ask and gives its id; the readers turn the answer services.take gives back into records.

Optional Pen adapter: all game state, timing and request policy are caller-owned.

Key items: Shape, Collider, Body, Motion, ball.
