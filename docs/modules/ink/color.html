ink/color

3 types · 44 values

HDR transfer functions, exposure, tone mapping curves, color grading, CDL, and LUT tables.

Key items: Grade, Cdl, Table, log2, logarithm.

blot · runnable example
let lin = linear_channel 0.5
let back = srgb_channel lin
abs (back - 0.5) < 0.001 // => true

Types

data Grade 
type Grade is data

Grading. grade is what Pen's present pass does to the exposed light, in linear light and in a log encoding of it (ACEScc: the Academy's S-2014-003 curve on the frame's own primaries, so no gamut change), where equal steps are equal stops. In order: a vignette; the exposure offset and white balance; contrast about the pivot in log; ASC CDL (slope gain, offset lift, power 1 / gamma) in linear light; saturation and vibrance about the luminance; then up to two look-up tables in log. Every setting at its neutral value is the identity. The host's shader, an f64 Rust reference and this are the same formula term for term.

temperature (-1 cooler to 1 warmer) moves red and blue half a stop against each other and tint (-1 greener to 1 more magenta) green against both, summing to no change in stops. contrast 1 keeps, 0 flattens to the pivot's grey. pivot is the linear luminance contrast leaves alone. vibrance positive boosts the duller colors, negative mutes the vivid. vignette darkens the corners to 1 - vignette, from vignette_radius of the way to a corner out. lut_a and lut_b name the host's tables, a material whose texture is the table's strip, as table material (0 for none, the wire's own number, so that a grade holds no boxed fields and settings[0].grade := g compiles); lut_blend blends the first toward the second and lut_weight is how much of the result applies.

data Cdl 
type Cdl is data

The ASC CDL part of a grade, per channel: lift is added after gain scales the light, and gamma is the reciprocal of the power. It is a record of its own beside Grade because Blot cannot assign a record of more than about sixteen scalar lanes into a field of an array's element (storage_unsupported), and a frame's settings are one: settings[0].grade := g and settings[0].cdl := c.

data Table 
type Table is data

A look-up table: size slices of size by size texels, as the host's strip holds them. texels are three floats each, texel (r, g, b) at ((g * size + b) * size + r) * 3, a color in the log encoding; an identity table holds (r, g, b) / (size - 1).

const histogram_bins 
const histogram_bins: U32

Exposure. A camera's exposure is a number of stops added to the scene's light; render.Exposure asks the host to find it from the picture (auto exposure). These are the calculations the host's GPU passes make, so a game can predict or check them: which histogram bin a luminance falls in, the average of the bins between two percentiles, the exposure that brings it to middle grey, and one step of adaptation toward it.

func histogram_bin

The bin of a linear luminance in histogram_bins bins evenly spaced in log2 over low to high; black, darker and brighter fall in the first and last.
