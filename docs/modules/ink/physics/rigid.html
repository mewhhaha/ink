ink/physics/rigid

3 types · 36 values

A sequential-impulse rigid body solver in the "soft step" style: contacts are found once per step, then the step is divided into substeps, each integrating velocities, applying (warm started) impulses against soft constraints, moving the bodies and relaxing the velocities. Many small substeps with a single iteration stack more stably than one step with many iterations.

All state is flat F32 arrays indexed by body slot, so a step allocates nothing per body. Slot -1 in a contact means an immovable world body.

Key items: Bodies, Soft, World, vec, quat.

const stride

A contact row holds what is fixed for the step (one row per contact point): 0 a, 1 b, 2-4 normal, 5-7 local anchor on a, 8-10 local anchor on b, 11 separation, 12 friction, 13 restitution, 14 normal mass, 15-16 tangent masses, 17-19 tangent 1, 20-22 tangent 2, 23 approach speed, 24-26 contact point, 28-29 entity ids of a and b. The impulses, which the solver updates, live apart (four per contact: normal, two tangential and the largest normal impulse), because the compiler updates an array in place only when it is never handed to another function.

const jac_stride 
const jac_stride: U32

Per contact the solver keeps, for the normal and both tangents d, how the bodies' velocities enter the contact's speed along d and how an impulse along d changes them. Twelve numbers per direction: rA x d, rB x d, I_A^-1 (rA x d), I_B^-1 (rB x d) then (36..41) the anchors rA and rB turned into the world. Zero where the body is immovable, so the passes need no branches. Recomputed whenever the bodies have turned.
