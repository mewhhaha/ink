ink/physics/d2/shapes

5 types · 70 values

Core 2D physics shapes, collision filters, AABBs, exact mass/inertia formulas, and caller-owned rigid body records. All shapes are plain value data (convex polygons store up to 8 CCW vertices inline) so Body2D arrays stay flat with zero nested owning-array allocations.

Key items: Filter2D, Aabb2, Poly2D, Shape2D, finite.
