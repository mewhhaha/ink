ink/physics/joints

3 types · 24 values

Endpoints refer to source array slots, never entity IDs. Anchors and joint axes are local to each source; static/kinematic endpoint poses are authored by the caller. Distance uses metres, spring N/m and N*s/m, motors rad/s (m/s on sliders) and Nm (N). Angles are radians.

Kinds: Distance/Spring keep one separation; Hinge keeps a point and an axis (angle lower..upper, motor about the axis); Ball keeps a point with an optional cone-twist limit (swing half-angle swing about the twist axis axis_a, twist range lower..upper) and an optional orientation drive; Slider keeps orientation and slides along axis_a (translation lower..upper, motor along the axis); Fixed locks point and orientation. rest is the relative rotation conj(a) * b at which angles are zero. Limits are soft unilateral rows and motors are soft/velocity rows; nothing is retained between substeps.

Key items: Kind, Joint, Link, distance, spring.

func solve_in_place 
func solve_in_place: F32 -> F32 -> #[F32] -> #[F32] -> #[F32] -> #[F32] -> #[Link] -> own #[F32] -> #[F32]

Sequential impulses, one pass per call (the caller substeps). Springs use implicit stiffness/damping; hinges solve three point rows and two angular rows, then motor and limit rows about their axis. Ball joints add swing, twist and orientation-drive rows; sliders lock two translations and all rotation; fixed joints lock all six. Limits are unilateral soft rows with speculative approach; position motors are soft springs. A motor applies at most torque*h impulse per substep. No hidden persistent state. The vector arithmetic runs on scalars in math's operation order.
