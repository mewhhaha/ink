ink/physics/scene

16 types · 74 values

What physics sees of a world: every entity with a collider, a body, a character or a brush becomes a proxy with a world-space shape and bounds. Callers build Source values from their own data. Queries (ray, shape cast, overlap) run against the scene built from those sources.

Key items: ShapeKind, BodyKind, Collider, Rigid, packed_proxy.

blot · runnable example
import * as math from "ink/math"
let sources = #[box 1 (math.vec3 0.0 0.0 (-5.0)) (math.vec3 2.0 2.0 2.0)]
let world = build_into (empty ()) sources
ray_any (read world) math.zero3 math.forward 10.0 65535 0 // => true
