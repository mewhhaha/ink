ink/physics/triggers

3 types · 4 values

Deterministic trigger volume lifecycle tracking (Enter, Stay, Exit) over full-width U32 (trigger, body) overlap pairs. Callers own the persistent previous-overlap pool; diff and step sort and deduplicate both sets and merge them in linear time.

Key items: Pair, Phase, Event, canonical, diff_canonical.
