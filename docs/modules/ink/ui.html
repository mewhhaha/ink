ink/ui

6 types · 83 values

Interface building blocks: headless controls that know their values and how keys and pointers change them but not how they look, the sprites that draw text, rectangles and panels for a game to compose them with, and the nodes that tell assistive technology and the keyboard what they are (at the end).

Key items: Control, Outcome, Line, StoredLine, label.
