ink/lanes

1 types · 24 values

A codec stores a value as F32 lanes, its type's section of a saved state (see persist.blot). key names that section from build to build: give each saved type its own and never change it. version names the layout of the lanes: change it whenever encode changes them. A state saved with another version restores through migrate, which, given that version, returns how to bring lanes saved with it to the current layout, or Nothing to start the type from its initial value. decode receives exactly the lanes that encode produced (or a migration made) and traps on anything else, rejecting the whole state.

Key items: Codec, require, no_migration, insert, finite.
