ink/editor

11 types · 151 values

A TrenchBroom-style level editor for convex brushes. Tab swaps between editing and playing; the level as edited comes back when play stops.

Key items: Mode, Tool, Editor, Settings, initial.

data Editor 
type Editor is data

What the primary button is doing. Each drag works from where it started: Draw extrudes a new box from the plane through start facing axis toward side, spawning created once it has an area. Move translates origin by the snapped motion of the point grabbed at anchor, vertically when vertical. Resize moves face face of origin along its normal as far as the pointer moves from anchor on it, in the shape's coordinates. Reshape drags corner corner of origin. Turn rotates origin as the pointer moves from (x, y): sideways about the vertical, or up and down about the camera's horizontal axis when tilt. face is a face of the selected brush picked with Shift. paint indexes Settings.materials. clips are the Clipper's points. view is the camera not in use: the editor's while playing, otherwise the last play camera.

data Settings 
type Settings begin copy is data

materials are the brush materials M cycles through; new brushes use the current one and extrude depth. The styles draw the selected brush, its selected face, corners and clip points; level draws the translucent plane at the bottom of a brush moving up or down, to compare heights against. view is where the editor camera starts, and begin runs with the editor camera whenever play starts.
