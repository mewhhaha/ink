ink/transform

4 types · 30 values

Poses are convenient inputs/interpolation values. Affine basis columns keep composition exact when rotated nonuniform scales introduce shear.

Key items: Pose2, Pose3, Affine2, Affine3, affine2.

blot · runnable example
import * as math from "ink/math"
let a = $Pose3 { position: math.zero3, rotation: math.identity_quat, scale: math.one3 }
let b = $Pose3 { position: math.vec3 10.0 0.0 0.0, rotation: math.identity_quat, scale: math.one3 }
(lerp3 a b 0.25).position.x // => 2.5

func affine2 
func affine2: Pose2 -> Affine2

Angles are radians; 3D uses Ink's right-handed quaternion convention.

The kernels below destructure their records first: each field then costs one node of the compiler's 64-node inlining budget, so they inline into callers' loops and their intermediate records become locals. Sums keep the order of the vector expressions they replace, such as value.x * v.x + value.y * v.y + value.z * v.z.

func column3 
func column3: F32 -> F32 -> F32 -> F32 -> F32 -> F32 -> F32 -> F32 -> Vec3

One basis column: unit axis (vx, vy, vz) turned by q, then scaled. Not math.rotate_parts: through it, affine3 in a loop ran 1.8 times slower.
