ink/kernel_transport

5 types · 36 values

Ephemeral Pen service::KERNEL (code 15) guest transport (blot2/tasks/CONCURRENCY_VNEXT.md §5.3).

Strictly separate from canonical ink/services.blot (which remains untouched with max_id = 16,777,215 and owns Save Schema 26 persistence):

  • Never persisted in Save Schema 26.
  • All incoming host->guest kernel traffic arrives exclusively on request == 0 ServiceAnswer + contiguous ServiceData events.
  • Outgoing service::KERNEL requests store payload strictly in transport.payload (never touching services.payload).
  • Stays strictly inert on Netplay ($window.Player) frames and whenever live-only CAP is inactive (while still absorbing recorded self-identifying BATCH_OK replies cleanly on replay / post-Moment restores!).

Key items: State, Waiting, Upload, BatchAnswer, owners.
