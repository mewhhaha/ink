ink/brush

2 types · 62 values

Editable Quake-style convex solid brushes with plane packing and face extraction.

Key items: Brush, Stored, pack, unpack, face.

Types

data Brush 
type Brush is data

A convex brush, as in Quake maps: its shape is the points p with dot(face.normal, p) <= face.distance for every face, and min and max bound its corners, kept up to date by every edit. The shape stays where it was made; the brush stands turned by rotation, then moved by offset, so turning and moving it never reshape it and can be undone exactly.

Constructors

  • faces: #[Face]
  • min: Vec3
  • max: Vec3
  • offset: Vec3
  • rotation: Quat
data Stored 
type Stored is data

Persistent ECS rows contain only scalar spans. The owning face pool is named separately. Brush values own their faces; packing writes spans into a pool.
