ink/render/probes

3 types · 14 values

A caller-owned volume of diffuse light probes: an axis-aligned lattice of nx x ny x nz points spacing apart from origin, probe index (z * ny + y) * nx + x. Each probe holds the light a white surface facing a normal would show there, as nine RGB spherical-harmonic terms in environment.basis order, the cosine lobe applied and divided by pi (what environment.diffuse gives for the sky), then a validity weight: 1, or 0 for a probe inside geometry. Probes live flat, stride floats each, in an owner the caller names; nothing here keeps state between calls.

Key items: Grid, Light, Sampled, count, lattice_position.

data Light 
type Light is data

What a bake lights with. Rays that escape see sky (its gradient, no sun) times tint, as environment.diffuse scales it; surfaces they hit reflect the sun (direction is the way its rays travel, as in render.Lighting) when no shadow ray reaches it, plus ambient (a sky environment.diffuse's coefficients) or, from a second bake on, the previous probes' light there. rays per probe go out along a spherical Fibonacci set up to reach metres, against the solids on mask layers.

data Sampled 
type Sampled is data

Where the point (no bias) or its bias-lifted lookup lands in the lattice is trilinear between eight probes; each corner's weight is its trilinear share times its validity times a smooth facing term (probes behind the surface weigh little), so a wall does not hand its other side's light through. confidence is 0 outside the lattice (fading in over one cell beyond its edge), and the share of valid corners inside: blend toward the sky with it. At a probe's centre the answer is exactly that probe's.

func bake_probe 
func bake_probe: Scene -> Light -> Grid -> (U32 -> Color) -> #[F32] -> U32 -> own #[F32] -> #[F32]

Bakes probe index into values (stride floats from index * stride): light.rays rays from the lattice point, the radiance each brings integrated onto nine SH terms. A probe whose rays mostly start inside a solid (or whose point is inside one) is invalid: zeros and validity 0. albedo says what colour entity id reflects. previous is an earlier bake of the same grid whose light lands in the hits (empty: the sky's ambient only), which is how bounces accumulate; it must not be values.

Bakes probes first up to first + budget (clamped to the grid): a game spends a fixed budget a frame and relights the day over many. resume says where the next call starts, wrapping to 0 after the last probe.
