ink/codec

12 types · 3 traits · 67 values

Library-owned word and F32-lane serialization traits plus #for #fields comptime record codecs.

Key items: Codec, LaneEncode, LaneDecode, Persistence, encode.

blot · runnable example
type Header is data = $Header { tick: U32, seed: U32 }
let words = encode_record 1 7 ($Header { tick: 12, seed: 99 })
let dec: Maybe Header = decode_record 1 7 words
let $Some h = dec else:
  return #[]
#[h.tick, h.seed] // => #[12, 99]

trait Codec 
type Codec a is trait

Blot's orphan rule prevents adding a std/codec implementation for F32 from Ink. This library-owned contract uses the same framing and generator, while admitting Ink's finite F32 policy and caller-owned custom implementations.

Members

  • value encode: a -> #[U32]
